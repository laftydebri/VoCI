# Tobacco Feedback Analysis Presentation

A modern web application for analyzing and presenting tobacco feedback data with interactive visualizations and comprehensive insights.

**Live Demo:** [tobacco-feedback-analysis-presentat.vercel.app](https://tobacco-feedback-analysis-presentat.vercel.app)

---

## 📋 Overview

This project provides a professional platform for tobacco feedback analysis, featuring data-driven insights, interactive dashboards, and detailed reporting capabilities. Built with modern web technologies to ensure scalability, performance, and user engagement.

### Key Features

- **Interactive Data Visualizations** — Explore feedback trends and patterns through intuitive charts and graphs
- **Comprehensive Analysis** — Deep dive into feedback categories, sentiment analysis, and behavioral insights
- **Responsive Design** — Seamless experience across desktop, tablet, and mobile devices
- **Export Capabilities** — Generate and share reports in multiple formats
- **Real-time Updates** — Live data processing and analysis

---

## 🛠️ Technology Stack

- **Frontend:** [Next.js](https://nextjs.org) 14+ (TypeScript)
- **UI Framework:** React with modern component architecture
- **Styling:** Tailwind CSS with responsive design
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js 16.x or higher
- npm, yarn, pnpm, or bun

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/laftydebri/tobacco-feedback-analysis-presentation.git
   cd tobacco-feedback-analysis-presentation
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.
